# Nota MVP 三分钟演示脚本

## 0:00 至 0:30 说明目标

打开 Web 控制台和架构图，说明本版本只验证一条完整链路：模拟硬件录音、异步 ASR、文字校准、Agent 工具调用、MQTT 通知和结果展示。

## 0:30 至 1:00 启动系统

展示 `npm run dev:all` 同时启动 Next.js、Worker 和 MQTT Broker。打开 `http://localhost:3000`，指出当前额度与空任务列表。

## 1:00 至 1:45 模拟硬件上传

在 Hardware Simulator 中录制：

> 明天下午三点完成 Nota 演示，提前一天提醒我，再查一下之前的报价。

停止录音并上传，展示立即返回的 `taskId`，以及 MQTT 更新的音频处理、ASR、校准、Agent、验证和完成阶段。

## 1:45 至 2:30 查看 Agent 过程

回到 Web 或用户 App，展示原始转写、校准文本、摘要，以及 `createTodo`、`setReminder`、`searchHistory` 的参数和执行结果。说明工具由模型按语义选择，而不是固定调用。

## 2:30 至 2:50 查询历史

在历史查询输入框中提问，展示 `searchHistory` 调用及引用的历史结果。强调第一版用简单文本检索，后续才考虑向量检索和重排序。

## 2:50 至 3:00 说明取舍

指出额度按成功业务任务扣除，ASR 内部调用不重复收费；MQTT 只通知，数据库和 HTTP 才是最终数据来源；第一版失败直接重新开始，以最少代码完成可讲清楚的闭环。
